"오늘도청춘" 앱의 모바일 화면 7개를 디자인해줘. 앱 이름은 "오늘도청춘"(영문 Still Young Days)이고, 70대 노안 어르신에게 자기 동네 노인 일자리를 큰 글씨 카드로 보여주고 전화 한 번으로 문의하게 해주는 안드로이드 앱이야.
사용자는 스마트폰이 익숙하지 않고, 카카오톡만 쓰는 수준이야. 앱 설치와 첫 설정은 자녀가 대신 해준다.

아래 [공통 제약]은 7개 화면 전부에 예외 없이 적용해줘. 화면은 1번부터 7번까지 순서대로, 각각 별도 프레임으로 만들어줘.

════════════════════════════════════════
[공통 제약 — 모든 화면에 필수]
════════════════════════════════════════

[절대 지켜야 할 수치]
- 본문 글자: 18~20sp (제목 24sp 이상, 캡션도 16sp 이상)
- 모든 버튼: 최소 64dp 높이 (비가역 동작은 72dp)
- 버튼 간 간격: 최소 12~16dp
- 명도 대비: 7:1 이상 (WCAG AAA) — 4.5:1로는 부족함
- 행간: 글자 크기의 1.5배
- 폰트 웨이트: 400~500만 사용 (Thin/Light 절대 금지)

[절대 하면 안 되는 것]
- 스와이프/롱프레스/더블탭/드래그로만 도달하는 기능 (탭만으로 전부 되어야 함)
- 아이콘만 있는 버튼 (반드시 글자 라벨 병기)
- 회색 저대비 텍스트
- 자동으로 사라지는 토스트/스낵바
- 색으로만 의미 구분 (색+아이콘+글자 3중으로)
- 청색과 녹색을 나란히 배치 (노안은 구분 못 함)
- 진한 청색을 검정 배경에 사용
- 비활성 버튼을 회색으로 흐리게 처리 (저대비 금지에 걸림 — 대신 눌렀을 때 안내 문구)

[톤]
- 밝은 배경 기본 (60세는 20세보다 3배 밝기가 필요함)
- 글자는 최소한으로. 한 화면에 한 가지 정보만
- 전문용어 금지: "공고"→"모집", "접수"→"신청"
- 날짜는 "8월 30일 (토)" 요일 병기, 시간은 "오전 10시" (24시제 금지)
- 긴 글은 말줄임(...) 하지 말고 줄바꿈
- 정보가 없는 항목은 아예 표시하지 말 것 ("정보 없음" 같은 문구 금지)
- 각 화면(스플래시 제외)에 크고 명확한 "◀ 뒤로" 버튼이 항상 보이게

════════════════════════════════════════
화면 1 — 스플래시
════════════════════════════════════════
앱 첫 실행 시 스플래시.
- 앱 이름 "오늘도청춘"을 아주 큰 글씨로 중앙에 배치
- 그 아래 "일자리를 불러오는 중입니다" 안내 문구
- 로딩 인디케이터는 크고 명확하게 (얇은 원형 스피너 금지)
- 1~2초 표시되며, 뒤에서 데이터 로딩과 위치 판정이 진행됨
- 빈 화면처럼 보이지 않아야 함

════════════════════════════════════════
화면 2 — 위치 권한 안내 (첫 실행)
════════════════════════════════════════
위치 권한을 요청하기 직전 설명 화면.
- 큰 글씨로 "어느 동네에 사시나요?" 질문
- 왜 위치가 필요한지 한 문장: "가까운 일자리를 보여드리려고 해요"
- 큰 버튼 2개를 세로로:
  ① "내 위치로 찾기" (주 버튼, 가장 크게)
  ② "직접 고를게요" (보조 버튼)
- 권한을 거부해도 앱을 쓸 수 있다는 게 명확해야 함
- 자녀가 대신 설정해줄 수 있는 화면이기도 함

════════════════════════════════════════
화면 3 — 홈 (카드 목록) ★ 핵심
════════════════════════════════════════
일자리 카드를 한 장씩 크게 보여주는 홈.
- 상단: 현재 지역 이름 ("김포시") + 지금 몇 번째인지 ("1 / 8") + 작은 캡션 "8월 28일 기준"
- 중앙 카드 (화면의 대부분을 차지):
  · 직무명 (가장 크게, 20sp 이상) — 예: "공원 환경정비"
  · 장소 (18sp) — 예: "김포시 사우동"
  · 큰 전화 버튼 "📞 전화하기" (64dp, 아이콘+글자 병기)
- 하단: "◀ 이전" / "다음 ▶" 큰 버튼 2개 (각 64dp)
  · 스와이프로도 넘어가지만, 버튼만으로 전부 가능해야 함
  · 첫 장/마지막 장에서도 버튼을 회색으로 죽이지 말고, 누르면 "첫 번째예요" 같은 안내가 뜨는 형태
- 카드 전체를 탭하면 상세로 이동
- 직무명이 길면 말줄임(...) 하지 말고 줄바꿈 (긴 제목 2줄 예시 하나 포함)
- 우상단 또는 하단에 "설정" 버튼 (글자 라벨 필수)
- 일자리가 없을 때의 빈 화면도 함께 디자인:
  "지금은 김포시에 모집 중인 일자리가 없어요" + "다른 동네 보기" 버튼

════════════════════════════════════════
화면 4 — 상세
════════════════════════════════════════
일자리 카드를 눌렀을 때의 상세 화면.
- 최상단에 크고 명확한 "◀ 뒤로" 버튼 (항상 보이게 고정)
- 직무명 (24sp 이상)
- 정보를 세로로 큼직하게, 각 항목마다 라벨 + 값. 순서는:
  · 하는 일 (여러 줄 본문. 급여나 근무 시간이 있으면 이 본문 안에 문장으로 들어 있음)
  · 장소 (전체 주소)
  · 모집 나이 (예: "60세 이상")
  · 신청 기간 (예: "8월 25일 (월) ~ 9월 7일 (일)")
  · 기관 (예: "김포시니어클럽")
- "받는 돈", "일하는 때" 같은 별도 항목은 만들지 말 것 (데이터에 없음)
- 화면 하단에 고정된 아주 큰 전화 버튼 "📞 전화하기" (72dp)
  · 이 화면에서 가장 크고 눈에 띄는 요소여야 함
  · 스크롤해도 항상 보이게
- 전화번호가 없는 일자리의 경우도 디자인: 전화 버튼 자리에 "전화번호가 없어요" 안내 (사라지지 않는 배너 형태)

════════════════════════════════════════
화면 5 — 설정
════════════════════════════════════════
설정. 항목이 4개뿐인 아주 단순한 목록.
- 각 항목은 64dp 이상 높이의 큰 행:
  ① "내 동네 바꾸기" — 현재 값("김포시")을 함께 표시
  ② "글자 크기" — 현재 값("보통")을 함께 표시. 선택지는 보통 / 크게 / 아주 크게
  ③ "알림 받기" — 큰 켜기/끄기 스위치 (스위치 옆에 "켜짐"/"꺼짐" 글자 병기)
  ④ "앱 사용법"
- 각 행에 오른쪽 화살표로 누를 수 있음을 표시
- 최상단에 큰 "◀ 뒤로" 버튼
- 설정 화면이라는 걸 큰 제목으로

════════════════════════════════════════
화면 6 — 지역 선택
════════════════════════════════════════
내 동네를 직접 고르는 화면. 시/도 17개 → 시군구 250개라 어려운 화면임.
- 2단계 구성 (두 단계를 각각 프레임으로):
  1단계: 시/도를 큰 버튼 그리드로 (한 줄에 2개씩, 각 72dp 이상). "전남광주통합특별시"처럼 긴 이름은 2줄 허용
  2단계: 선택한 시/도의 시군구를 세로 큰 목록으로. "수원시"처럼 구가 있는 시는 구를 펼치지 않고 "수원시" 한 줄로
- 현재 선택된 지역을 상단에 크게 표시
- "내 위치로 다시 찾기" 버튼을 상단에 배치 (GPS 재시도)
- 각 단계마다 큰 "◀ 뒤로" 버튼
- 검색창은 넣지 말 것 (키보드 입력은 어르신에게 큰 장벽)

════════════════════════════════════════
화면 7 — 앱 사용법
════════════════════════════════════════
앱 쓰는 법 안내. 자녀가 어르신께 설명할 때도 쓰임.
- 3~4개 단계를 세로로, 각 단계마다:
  · 큰 번호 (①②③)
  · 한 문장 설명 (18sp 이상)
  · 간단한 그림 또는 실제 화면 축소 이미지
- 예시 문구:
  ① "화면에 일자리가 한 개씩 나와요"
  ② "다음 버튼을 누르면 다른 일자리를 봐요"
  ③ "마음에 들면 전화하기를 누르세요"
- 맨 아래 큰 "알겠어요" 버튼

════════════════════════════════════════
마지막으로
════════════════════════════════════════
- 7개 화면이 같은 색·글자·버튼 체계를 쓰도록 디자인 토큰(배경색, 본문색, 주 버튼색, 글자 크기 단계, 버튼 높이)을 먼저 정하고 그 값을 표로 함께 알려줘. 본문/배경, 버튼 글자/버튼 바탕 두 조합의 명도 대비 수치를 계산해서 적어줘 (둘 다 7:1 이상이어야 함).
- 화면 3(홈)과 화면 4(상세)는 글자 크기 200%로 키운 버전도 한 장씩 추가로 만들어줘. 레이아웃이 깨지지 않는지 보려는 거야.
